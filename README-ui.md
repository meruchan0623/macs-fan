# 紧凑控制工具界面

0.5.0 默认560×440，最小460×340。单窗口直接显示风扇与温度表，去掉侧栏、装饰图和常驻说明。风扇与传感器独立滚动，16风扇fixture在最小窗口下仍保留底栏。

搜索、温度排序、手动刷新在主窗口；曲线、诊断和来源说明按需打开原生HTML dialog，可Esc关闭并恢复焦点。曲线仍是预览；只读状态常驻。不会显示虚构的“已应用”控制成功。

数据经Tauri snapshot调用读取；无桥接时明确离线。只有显式?demo=1提供带横幅的演示。失败与过期立即移除旧值。真实读数仅通过安全DOM插入，来源保留在行tooltip与辅助技术标签。

浏览器验收使用ego-browser：560×440、460×340、16风扇最小窗口、搜索、无桥接、dialog及错误阈值。生产包另做原生窗口验收。

0.3增加“概览/部件/全部”范围。概览按CPU、GPU、电池及其他部件排序；没有可用均值时显示实际可用成员，不隐藏整个类别。不在主窗口增加解释段落，所有映射和质量依据保留在悬停及诊断中。

0.4增加菜单栏入口与关闭后驻留，Dock可唤回；同源别名仅用于搜索和悬停，不生成重复行。传感器范围匹配补齐触控板等部件，窗口尺寸和信息密度不变。

0.5保留同一布局：HID与SMC独立数据来源的说明放悬停/诊断；同名HID歧义部件在部件/全部中查看，避免默认概览出现多条重复名称。
